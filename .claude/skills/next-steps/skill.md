# Next Steps

Very concisely, describe the next steps for this workstream.

This is useful in a few situations:
* The user is returning after a while away, and wants a concise re-orientation.
* The user is trying to decide where to proceed after reaching the end of a session task.
* The user wants to be reminded of an earlier slate of work items discovered in the session.
  If you earlier identified a list of potential work items through an audit or investigation,
  list those that remain to be done.
* The user wants to know if the session can be closed out without losing valuable insight.
  If the session can be safely closed, with or without the option to file minor tangential
  tickets, please state that clearly.

Please present these follow-ups as concisely as possible; the user will decide where to dig in
or request more information. One to three short sentences is sufficient for each, ideally
avoiding session-level jargon when possible and focusing on tangible outcomes rather than
in-the-weeds statements about particular code paths.
